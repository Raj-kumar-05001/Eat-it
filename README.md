# 🍴 EatIt — Good Food, Happier You

EatIt is a modern and responsive food ordering website designed to provide a clean, attractive, and user-friendly experience for discovering delicious meals.

The website features a visually appealing food-focused interface with promotional banners, food categories, popular food items, special offers, and a responsive layout suitable for desktop, tablet, and mobile devices.
